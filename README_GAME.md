# Dustline: Colossus Protocol

Protótipo 2D arcade run-and-gun original, sem copiar personagens, sprites, fases, nomes ou áudio de obras existentes.

## Rodar
Abra `index.html` em um navegador moderno. Não requer servidor ou dependências externas.

## Controles
- A/D ou ←/→: mover
- W/↑/Espaço: pular
- S/↓: agachar
- Z: atirar
- X: granada
- 1–4: trocar arma
- R: reiniciar após morte/vitória
- Enter/Espaço: iniciar no menu

Em celular há controles touch básicos.

## Conteúdo
Uma fase com progressão por distância, soldados básicos/agressivos/pesados, pickups, tanque, helicóptero, projéteis, granadas, explosões, screen shake e boss Colosso MK-I em três fases.

A arte é desenhada por formas pixeladas no Canvas para manter o projeto leve e sem assets protegidos.
